# let,const

块级作用域: 作用域函数内部或者 {} 之间

1.不会提升。

2.重复声明报错。

3.不绑定全局作用域(window 或者 global)。

let 可以修改，const 不可以

暂时性死区 TDZ: 在函数开始到变量声明中间，为 TDZ，即不能访问 let 或者 const 声明的变量 在全局作用域，不存在变量提升；在块级作用域，存在变量的创建提升 a

// 由于TDZ，会报错
var value = "global";

// 例子1
(function() {
	console.log(value);

	let value = "local";
})();

在 for 循环中采用 let 的话，底层处理会在循环（）内创建隐藏作用域,声明一个新的迭代变量

# 函数参数默认值

// 写法一,给参数默认值x=0,y=0
function m1({ x = 0, y = 0 } = {}) {
	return [x, y];
}

// 写法二,如果没有传参，则为[0,0],不然为undeifined
function m2({ x, y } = { x: 0, y: 0 }) {
	return [x, y];
}

# class

class 的本质其实是一个包裹的函数，通过 babel 可知:

class t {
	constructor() {
		console.log(1);
	}
	say() {}
	static a() {}
}
// ===

var t = /*#__PURE__*/ (function() {
	function t() {
		console.log(1);
	}

	var _proto = t.prototype;

	_proto.say = function say() {};

	t.a = function a() {};

	return t;
})();

# 箭头函数

  1. 箭头函数 this 指向父级作用域的 this
  2. call/apply/bind 无法更改箭头函数的 this
  3. 不能被当作构造函数
  4. 不可以使用 arguments 对象(可以使用...args)
  5. 不能使用 new.target(用于检测是否通过 new 来调用)
